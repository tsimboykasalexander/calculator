# Calculator

A python 3 calculator used from the Terminal, build step by step in SCCM4910

##What it will do
Add, subtract, multiply and divide 2 numbers; display the result.

##How to run it
From Week3: python3 calculator.py. using ./run.sh

Enter the first number, operator(+ - * /), then second number.
the program prints Result: followed by the answer displaying the Result of the opporator on the 2 numbers entered

To stop the Program use a keybourd interupt Ctrl + C

to run the tests run ./check.sh all should pass, and the exit status should return 0
